Diagrama de Pinos e Conexões (Pinout)

Como conectar os atuadores, o sensor e a fonte na Mini Protoboard e no Arduino Nano.

📡 SENSOR ULTRASSÔNICO HC-SR04
  • VCC -> 5V (Arduino)
  • GND -> GND (Geral)
  • TRIG -> PINO D2
  • ECHO -> PINO D3
📳 MOTOR MOEDA VIBRACALL PWM D5
  • Pólo (+) -> Resistor 220Ω -> PINO D5
  • Pólo (-) -> GND (Arduino)
  • Sinal -> Modulação PWM
🔊 BUZZER ATIVO 5V PINO D6
  • Pino (+) -> PINO D6
  • Pino (-) -> GND (Arduino)
  • Disparo -> Bipe Frequencial
🔋 ALIMENTAÇÃO AUTÔNOMA 9V BATERIA
  • Bateria (+) -> Chave Liga/Desliga
  • Chave Out -> PINO VIN (Arduino)
  • Bateria (-) -> PINO GND

Para Que Serve o Boné Sensorial?

Um radar vestível projetado para cobrir o "ângulo cego" da bengala tradicional.

Detectar Obstáculos Altos

Funciona como um "radar de cabeça". Ele escaneia a altura do peito e do rosto da pessoa, identificando orelhões, galhos de árvores, placas de trânsito e portões abertos.

Calcular Distância em Tempo Real

O sensor emite ondas de som (como um morcego ou um sonar de navio). O som bate no objeto, volta para o boné e o Arduino calcula a quantos centímetros o obstáculo está.

Avisar pelo Tato

Transforma a distância em vibração física na testa do usuário. Quanto mais perto o objeto estiver, mais forte ou mais rápido o boné vibra.

// BENEFÍCIOS PRÁTICOS

Como Pode Ajudar no Dia a Dia?

Evita Acidentes Graves

Pancadas na cabeça e no rosto são os acidentes mais comuns e dolorosos para pessoas cegas nas ruas. O boné evita esses traumas antes do impacto.

Liberdade para as Mãos

Por ser um dispositivo vestível (wearable), a pessoa não precisa segurar nada. Suas mãos ficam livres para carregar sacolas, abrir portas ou usar o celular.

Trabalha em Dupla com a Bengala

Enquanto a bengala tradicional protege as pernas e mapeia o chão (buracos e degraus), o boné protege a parte de cima do corpo. Juntos, eles criam uma proteção completa.

Ajuda a Manter a Postura

Dá mais confiança para a pessoa caminhar com a cabeça erguida, sem o medo constante de trombar em algo.

// APLICAÇÃO NO AMBIENTE ESCOLAR

Para Qual Finalidade na Escola?

Obstáculos nos Corredores

Escolas costumam ter extintores de incêndio pendurados na parede, bebedouros salientes, armários abertos ou murais de aviso com quinas. Alunos cegos podem trombar nesses objetos antes que a bengala toque o chão. O boné resolve isso alertando sobre essas barreiras aéreas.

Ambientes Movimentados (Pátios)

Na hora do intervalo, o pátio fica cheio de pessoas mudando de direção o tempo todo, mochilas jogadas e cadeiras fora do lugar. O boné ajuda o estudante a navegar por esse fluxo caótico sem colisões.

Portas Entreabertas

Uma porta de sala de aula deixada pela metade é uma das maiores causas de acidentes de rosto. O sensor na aba do boné detecta a folha da porta imediatamente.

Código C++ Real Pronto para Arduino IDE

Código de robótica profissional com filtro de média móvel, controle PWM de vibração e lógica não-bloqueante via millis().

Bone_Sensorial_Robotica.ino 
/* =====================================================================
 * PROJETO ROBÓTICA: BONÉ SENSORIAL DE ACESSIBILIDADE
 * HARDWARE: Arduino Nano V3.0 (ATmega328P)
 * SENSORES: HC-SR04 | ATUADORES: Motor Moeda 5V (PWM D5) e Buzzer (D6)
 * ===================================================================== */

#define PIN_TRIG 2       // PINO TRIGGER (SAÍDA ULTRASSÔNICA)
#define PIN_ECHO 3       // PINO ECHO (ENTRADA ULTRASSÔNICA)
#define PIN_MOTOR 5      // PINO PWM DO MOTOR VIBRACALL
#define PIN_BUZZER 6     // PINO DO BUZZER ATIVO DE 5V

const int DISTANCIA_MAX = 120;  // 1.20 METROS (ALERTA PREVENTIVO)
const int DISTANCIA_CRITICA = 30; // 30 CM (PERIGO IMINENTE NA CABEÇA)

unsigned long tempoAnterior = 0;
const long intervaloLeitura = 50; // LEITURA A CADA 50ms

// FILTRO DE ROBÓTICA: MÉDIA MÓVEL DE 5 LEITURAS
const int NUM_LEITURAS = 5;
int leituras[NUM_LEITURAS];
int indiceLeitura = 0;
long somaLeituras = 0;

void setup() {
  pinMode(PIN_TRIG, OUTPUT);
  pinMode(PIN_ECHO, INPUT);
  pinMode(PIN_MOTOR, OUTPUT);
  pinMode(PIN_BUZZER, OUTPUT);

  digitalWrite(PIN_TRIG, LOW);
  analogWrite(PIN_MOTOR, 0);
  digitalWrite(PIN_BUZZER, LOW);

  Serial.begin(9600);

  for (int i = 0; i < NUM_LEITURAS; i++) {
    leituras[i] = 0;
  }
}

int obterDistanciaUltrassonica() {
  digitalWrite(PIN_TRIG, LOW);
  delayMicroseconds(2);
  digitalWrite(PIN_TRIG, HIGH);
  delayMicroseconds(10);
  digitalWrite(PIN_TRIG, LOW);

  long duracao = pulseIn(PIN_ECHO, HIGH, 30000);
  if (duracao == 0) return DISTANCIA_MAX + 1;
  return duracao * 0.0343 / 2;
}

void loop() {
  unsigned long tempoAtual = millis();

  if (tempoAtual - tempoAnterior >= intervaloLeitura) {
    tempoAnterior = tempoAtual;

    somaLeituras -= leituras[indiceLeitura];
    leituras[indiceLeitura] = obterDistanciaUltrassonica();
    somaLeituras += leituras[indiceLeitura];
    indiceLeitura = (indiceLeitura + 1) % NUM_LEITURAS;

    int distanciaFiltrada = somaLeituras / NUM_LEITURAS;

    Serial.print("Distancia Real: ");
    Serial.print(distanciaFiltrada);
    Serial.println(" cm");

    if (distanciaFiltrada <= DISTANCIA_MAX && distanciaFiltrada > 0) {
      int intensidadeVibracao = map(distanciaFiltrada, DISTANCIA_MAX, DISTANCIA_CRITICA, 90, 255);
      intensidadeVibracao = constrain(intensidadeVibracao, 90, 255);

      analogWrite(PIN_MOTOR, intensidadeVibracao);

      if (distanciaFiltrada <= DISTANCIA_CRITICA) {
        digitalWrite(PIN_BUZZER, HIGH);
      } else {
        digitalWrite(PIN_BUZZER, (tempoAtual / 150) % 2);
      }
    } else {
      analogWrite(PIN_MOTOR, 0);
      digitalWrite(PIN_BUZZER, LOW);
    }
  }
}
